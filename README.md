# Alley Cat Ink Website

A production static website for Alley Cat Ink, a tattoo and piercing studio in Hutchinson, Minnesota.

Live site: [www.alleycatinkmn.com](https://www.alleycatinkmn.com)

## Overview

The site presents the studio, tattoo work, flash designs, piercing services, and booking contact path through a responsive single-page experience.

## Technical approach

- Static HTML, CSS, and JavaScript
- Responsive layout for desktop and mobile
- Video-backed hero and service sections
- Optimized gallery and flash-design presentation
- Search and social metadata for the public site
- No framework or build step required

## Local development

This is a static site. Open `index.html` in a browser for a quick local preview, or serve the repository root with any local HTTP server.

## Deployment

The repository is configured for deployment from the project root. Vercel can use the **Other** framework preset with the repository root as the output directory.

## Site structure

- `index.html` contains the page markup, styles, and client-side behavior.
- `media/` contains the site imagery, video, icons, and gallery assets.
- `robots.txt` and `sitemap.xml` support search indexing.
